# 灵工云（本机长期维护版）

双击 `启动.command` 即可在默认浏览器打开项目入口。

项目不依赖临时服务或云端部署；当前 `index.html` 是可直接运行的 v0.1 原型基线。后续页面与流程将按照 `src/` 的企业端、个人端、运营端和共享模块边界逐步迁移，避免继续向单一文件堆积。

## 项目导航

- `docs/`：产品概述、角色权限、核心流程、页面清单、设计规范和变更记录。
- `src/`：后续模块化源码的归属目录。
- `public/`：图片、图标与品牌资源。
- `scripts/`：本机启动、检查与后续维护脚本。
- `.github/`：需求、问题与合并请求模板。
- `index.html`：当前可运行的高保真原型。
- `启动.command`：本机一键打开入口。

## 维护约定

1. 先更新 `docs/` 中的页面清单和流程，再改页面。
2. 每一批可用改动提交一次 Git，提交说明描述业务目的。
3. 新页面放入对应角色模块；仅复用内容进入 `src/shared/`。
