# 核心业务流程

1. 企业入驻：开户注册 → 企业认证 → 平台审核 → 审核通过 → 企业工作台。
2. 个人入驻：登录注册 → 实名认证 → 绑定收款银行卡 → 平台审核 → 审核通过 → 可报名任务。
3. 人员协作：企业发布任务 → 个人浏览/报名 → 企业确认合作 → 个人执行服务并提交交付物。
4. 双层验收：个人提交交付物 → 平台审核交付 → 审核通过后提交企业验收 → 企业确认/驳回；企业驳回时退回个人修改，平台保留审核记录。
5. 受托结算：企业确认交付 → 平台生成企业结算单 → 企业向平台付款 → 平台确定个人交付定价与可结算金额 → 平台向个人支付报酬。
6. 税费处理：平台在个人报酬结算时计算应缴税费 → 代扣代缴 → 生成个人结算单、税费明细与支付记录。
7. 发票管理：企业申请发票 → 平台审核开票信息并处理开票 → 企业查看开票与寄送进度。
8. 运营风控：运营人员可审核企业/个人准入、个人交付、定价与结算；对异常任务、结算和税费记录进行处理与留痕。
# 企业移动端合作流程

企业完成认证后，可在达人库按内容领域、粉丝量级与平台筛选候选达人；创建合作任务并发布需求；查看报名与候选达人，确认合作后跟进交付、结算与发票。
