# 核心业务流程

1. 企业入驻：开户注册 → 企业认证 → 工作台 → 发布任务 → 任务列表。
2. 人员协作：企业任务详情 → 个人浏览任务 → 报名接单 → 企业确认 → 服务完成。
3. 结算支付：任务完成 → 创建订单 → 支付确认 → 支付成功 → 交易记录。
4. 个人成长：登录注册 → 实名认证 → 绑定银行卡 → 浏览任务 → 接单 → 收入与提现。
5. 平台审核：企业提交认证 → 审核列表 → 审核详情 → 通过/驳回 → 企业收到结果。
6. 发票申请：企业申请发票 → 平台发票管理 → 开票处理 → 企业查看进度。
# 机构移动端合作流程

机构完成认证后，可在达人库按内容领域、粉丝量级与平台筛选候选达人；创建合作任务并发布需求；查看报名与候选达人，确认合作后跟进交付、结算与发票。
