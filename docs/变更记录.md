# 变更记录

## v0.2.0（规划中）

- 建立产品文档、页面清单、流程与设计规范。
- 建立企业端、个人端、运营端及共享模块的目录边界。
- 现有 `index.html` 作为 v0.1 可运行原型基线保留。

## v0.1.0

- 创建本机可直接打开的灵工云高保真交互原型。
- 包含三端入口与核心流程演示。
# 2026-07-30｜个人端移动原型升级

- 依据登录首页、达人广场、任务、个人中心四组移动端设计稿，将个人端改造为独立手机端界面。
- 新增首页、服务者广场、任务、交易、我的五栏导航，以及登录、任务详情、确认报名、认证、银行卡与提现流程。
- 保留灵工云的任务、收入、认证业务语义；“达人广场”在本项目中表达为服务者生态与合作机会入口。
# 2026-07-30｜企业移动端原型

- 新增基于企业版设计稿的企业移动端：首页、达人库、任务、交易、我的五栏导航。
- 新增企业发布合作需求、查看候选达人、合作任务与交易结算流程。
- 企业桌面后台同步转为企业达人合作业务语义，覆盖达人库、合作任务与结算管理。
# 2026-07-30｜运营主导审核与结算规则

- 明确企业和个人均须完成注册认证并通过运营审核后，方可进入对应业务流程。
- 个人交付物采用“平台先审、企业后验收”的双层审核机制。
- 企业向平台结算；平台拥有个人交付定价和个人报酬结算权，并负责支付时的税费代扣代缴。
- 补充运营端的个人审核、交付审核、定价、企业/个人结算、税费和发票管理职责。
# 2026-07-30｜运营端二级导航与模块扩展

- 运营端左导航调整为支持二级类目的结构，并按企业、零客、项目、任务、发票等业务域分组。
- 补充结算、税费、合同、数据中心与系统管理入口，以及各模块的列表原型。
# 2026-07-30｜运营端二级菜单交互

- 二级菜单支持展开与收起；保留父级菜单进入对应管理列表的能力。
# 2026-07-30｜新签审核列表细化

- 新签审核增加全部、待审核、已审核筛选，补齐编号、企业名称、审核状态、提交时间、审核时间与操作列。
- 提交时间和审核时间统一展示至秒级。
# 2026-07-30｜运营端新增企业录入

- 企业管理新增“新增企业”二级入口，供运营人员代企业录入基础信息、联系人和结算资料。
# 2026-07-30｜新增企业归入企业运营管理

- 移除独立的“新增企业”导航入口；改由企业运营管理页展示新增记录，并通过右上角按钮进入新增企业录入页。
- 新增记录列表补充企业基本信息、提交人员和精确到秒的提交时间。
# 2026-07-30｜更正新增企业导航排序

- “新增企业”恢复为企业管理下的二级菜单，排在“运营管理”之后；新增记录列表与信息录入页保留为两级页面关系。
# 2026-07-30｜企业运营管理列表细化

- 企业运营管理改为企业账号列表，显示编号、企业名称、统一社会信用代码、末次登录时间、账号状态与操作。
- 移除通用状态筛选栏；末次登录时间统一展示至秒级。
# 2026-07-30｜全局列表分页

- 所有通用及运营端自定义列表扩展至 20 条样例数据，默认展示 10 条。
- 新增统一分页组件，支持 10、20、40、50 条/页和翻页操作。
# 2026-07-30｜优化列表企业样例数据

- 分页列表中的企业样例改为不同企业名称，并对样例编号做区分，避免产生重复业务记录的歧义。
# 2026-07-31｜明确运营端一级菜单规则

- 有二级菜单的一级项取消独立页面，仅承担分类展开/收起功能；无二级菜单的一级项保留独立页面。
# 2026-07-31｜零客运营管理列表细化

- 零客运营管理增加手机号、姓名、脱敏身份证号、账号状态、注册时间、技能标签、履约评分与操作字段。
# 2026-07-31｜补充零客认证与签约状态

- 零客运营管理增加实名认证和签约状态字段，并以状态标签展示。
# 2026-07-31｜项目审核列表细化

- 项目审核增加编号、项目名称、企业名称、审核状态、提交时间、审核时间与操作字段。
# 2026-07-31｜统一企业与项目审核状态

- 新签审核与项目审核统一为全部、待审核、已通过、已驳回四类筛选状态，并与分页联动。
# 2026-07-31｜项目进度管理列表

- 项目进度管理增加全部、进行中、未开始、已关闭筛选，显示剩余时间与操作；剩余时间按天数或“不足1天”展示。
