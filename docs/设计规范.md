# 设计规范

- 基础体系：Ant Design 的企业级信息层级与组件习惯；项目令牌定义在 `src/shared/tokens/design-tokens.css`。
- 主色：`--lg-primary` 用于主要动作与系统状态；`--lg-success` 用于完成态和个人端辅助识别。
- 首页：企业与个人为主要服务入口；运营后台隐藏在页脚内部入口。
- 通用组件：组件名称、映射关系与使用规则见《组件清单》。
- 业务页面：同类列表统一使用筛选 Tab、表格与详情入口；同类表单统一使用双列字段与提交反馈。
- 状态语义：警告（待审核、待付款）、进行中（执行/报名）、成功（完成/支付）、错误（驳回）。
- 个人端移动规范：以 390px 宽度为基准；蓝色渐变用于品牌头部、账户信息与登录页，内容区采用白底卡片；主导航固定为首页、广场、任务、交易、我的五项。桌面预览以手机框展示，小屏设备全宽呈现。
- 运营端导航：具有二级类目的一级菜单仅作为展开/收起分类，不设置独立页面；所有功能进入对应二级页面。无二级菜单的一级项才配置独立页面。
- 列表分页：所有列表均提供 20 条样例数据，默认每页显示 10 条；支持切换 10、20、40、50 条/页，以及上一页、页码、下一页操作。
