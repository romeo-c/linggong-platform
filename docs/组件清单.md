# 公共组件清单

组件遵循 Ant Design 的使用边界：先使用通用组件，再在业务模块中组合，不为单一页面复制实现。

| 组件 | 对应 Ant Design 能力 | 用途 |
| --- | --- | --- |
| `AppLayout` | Layout、Menu、Breadcrumb | 三端后台框架、导航与面包屑 |
| `PageHeader` | PageHeader 模式、Button | 页面标题、描述和主要操作 |
| `DataTable` | Table、Tabs、Pagination | 任务、订单、审核、交易等业务列表 |
| `StatusTag` | Tag、Badge | 审核、任务、支付与发票状态 |
| `BusinessForm` | Form、Input、Select、DatePicker、Upload | 认证、任务、订单、结算与发票表单 |
| `DetailPanel` | Descriptions、Card | 项目、任务、人员、订单详情 |
| `ConfirmAction` | Modal、Popconfirm、Message | 支付、审核、提现、驳回等确认动作 |

## 使用规则

1. 状态文字必须使用 `StatusTag` 和统一状态字典，不自行定义颜色。
2. 所有列表页采用“标题区 → 筛选 Tab → 表格 → 详情入口”的顺序。
3. 所有新增和编辑操作采用 `BusinessForm`；高风险动作必须有确认反馈。
4. 页面内只保留一个主要操作按钮。
