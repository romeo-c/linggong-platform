# 灵工云产品概述

灵工云是面向企业、自由职业者与平台运营人员的社会化灵活用工协同系统。

## 产品目标

- 企业：完成注册认证、项目与任务发布、候选人员协作、交付验收、向平台结算及发票管理。
- 个人：完成注册认证、接单、提交服务交付物、查看审核结果、收入与提现管理。
- 平台：作为审核与结算主体，完成企业/个人准入审核、个人交付审核、交付定价、企业收款、个人报酬结算、代扣代缴税费、发票与风控管理。

## 结算原则

企业只向平台支付结算款；平台审核个人交付并确定可结算金额后，再向个人支付报酬。平台在支付个人报酬时，负责计算、代扣代缴应缴税费，并形成可追溯的结算、税费与支付记录。

## 当前阶段

当前为高保真、可交互原型；不接入实名、银行、支付、电子签章或外部数据接口。
