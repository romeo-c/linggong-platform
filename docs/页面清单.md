# 页面清单

## 企业端

工作台、开户注册、企业认证、项目管理、任务管理、任务详情、候选人员管理、企业验收、企业结算单、支付确认、财务管理、发票申请与开票进度。

## 企业移动端

首页、达人库、任务管理、交易管理、企业中心、任务详情、发布合作需求。基于企业版移动设计稿，面向企业筛选达人、发布合作任务、管理交付与结算。

## 个人端（移动端）

五栏底部导航：首页、服务者广场、任务、交易、我的。

支持页面：登录注册、实名认证、银行卡管理、任务详情、确认报名、交付物提交、审核结果、收入交易、税费明细与提现。个人端以手机端为主，不使用企业端的侧边栏后台布局。

## 平台运营端

运营工作台、企业审核、个人审核、企业管理、个人管理、任务管理、个人交付审核、交付定价、企业结算管理、个人结算管理、税费管理、发票管理、风控处理、系统管理。

每个页面新增或调整时，需要同步更新此清单与对应业务流程。
