# 页面清单

## 企业端

工作台、开户注册、企业认证、项目管理、任务管理、任务详情、零客管理、订单中心、支付确认、财务管理、发票申请。

## 机构移动端

首页、达人库、任务管理、交易管理、机构中心、任务详情、发布合作需求。基于机构版移动设计稿，面向机构筛选达人、发布合作任务、管理交付与结算。

## 个人端（移动端）

五栏底部导航：首页、服务者广场、任务、交易、我的。

支持页面：登录注册、实名认证、银行卡管理、任务详情、确认报名、收入交易与提现。个人端以手机端为主，不使用企业端的侧边栏后台布局。

## 平台运营端

运营工作台、企业审核、企业管理、零客管理、订单管理、发票管理、系统管理。

每个页面新增或调整时，需要同步更新此清单与对应业务流程。
