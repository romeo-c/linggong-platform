# 页面清单

## 企业端

工作台、开户注册、企业认证、项目管理、任务管理、任务详情、候选人员管理、企业验收、企业结算单、支付确认、财务管理、发票申请与开票进度。

## 企业移动端

首页、达人库、任务管理、交易管理、企业中心、任务详情、发布合作需求。基于企业版移动设计稿，面向企业筛选达人、发布合作任务、管理交付与结算。

## 个人端（移动端）

五栏底部导航：首页、服务者广场、任务、交易、我的。

支持页面：登录注册、实名认证、银行卡管理、任务详情、确认报名、交付物提交、审核结果、收入交易、税费明细与提现。个人端以手机端为主，不使用企业端的侧边栏后台布局。

## 平台运营端

左导航支持二级类目：工作台；企业管理（新签审核、运营管理、新增企业）；零客管理（零客招募、运营管理）；项目管理（项目审核、进度管理）；任务管理（任务审核、执行管理）；结算管理；发票管理（开票申请、已开发票）；税费管理；合同管理；数据中心；系统管理。具有二级类目的一级项不设置独立页面，仅用于展开或收起对应二级项。企业运营管理列表显示编号、企业名称、统一社会信用代码、末次登录时间、账号状态和操作，不设置通用状态筛选栏。零客运营管理列表显示编号、手机号、姓名、脱敏身份证号、实名认证、签约状态、账号状态、注册时间、技能标签、履约评分和操作。项目审核列表显示编号、项目名称、企业名称、审核状态、提交时间、审核时间和操作。新增企业位于企业运营管理之后，进入后展示运营人员代企业新增的记录，包含企业基本信息、提交人员与提交时间，并在右上角提供“新增企业”进入下一级录入页。新签审核页支持全部、待审核、已审核筛选，列表显示编号、企业名称、审核状态、提交时间、审核时间、操作，时间精确到秒。

每个页面新增或调整时，需要同步更新此清单与对应业务流程。
